# CivTech-Allocat

A cloud-based workflow automation and case management platform designed to manage grant applications, assessment workflows, eligibility verification, interviews, approvals, reporting, and beneficiary management.

## Key Features

- Online application management
- Eligibility assessment
- Workflow automation
- Interview scheduling
- Document verification
- Role-based access control
- Audit logging
- Dashboards and reporting
- Email notifications
- API integrations

## Technologies

- Google Apps Script
- JavaScript
- HTML
- CSS
- Google Workspace
- REST APIs
